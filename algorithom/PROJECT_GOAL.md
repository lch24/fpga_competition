# FPGA 相机畸变校正系统 — 总体目标

---


## 一、总目标

> **实现一套基于 FPGA 的实时图像采集 → 畸变参数计算 → 在线矫正流水线系统。**

拆解为以下三个核心阶段：

### 阶段 1：相机采样与图像输入
- 通过 FPGA 的视频采集接口（如 MIPI CSI / HDMI / DVP）从摄像头实时获取图像帧
- 写入帧缓存（DDR 或 BRAM），供后续模块读取

### 阶段 2：畸变参数计算（标定）
- 使用棋盘格标定板，采集多张不同角度的标定图像
- 检测角点 → 求解内参矩阵 `K` 和畸变系数 `(k1, k2, p1, p2, k3)`
- **标定完成后参数固定，存入寄存器/ROM，运行时不再重算**

### 阶段 3：实时图像矫正（运行态）
- 每次从摄像头读入一帧新图像
- 根据阶段 2 得到的参数，执行去畸变运算
- 输出矫正后的图像流

---


## 二、算法到硬件的映射

| 算法步骤 | PC (OpenCV) | FPGA 实现思路 |
|----------|-------------|----------------|
| 角点检测 | `findChessboardCornersSB` | 灰度化 → 阈值分割 → 连通域/模板匹配（或用现有的开源硬件加速器） |
| 亚像素优化 | `cornerSubPix` | 基于邻域梯度的迭代优化，可用流水线加速 |
| `calibrateCamera` | Levenberg-Marquardt 非线性优化 | 定点数运算 + 迭代求解器（可考虑软核 CPU 跑 ARM/AXI） |
| `initUndistortRectifyMap` | 为每个像素计算映射坐标 | **一次性预计算**映射表，存入 BRAM/ROM |
| `remap` (双线性插值) | `cv::remap` | 状态机逐像素读取映射表 → 邻域取值 → 加权平均 → 写回 |

> 💡 **关键优化**：畸变参数固定后，`(src_x, src_y) = f(dst_x, dst_y, K, dist)` 对每个输出像素的映射坐标是不变的。因此最适合硬件的方案是 **预计算整张映射表**，运行时只需查表 + 插值。

## 三、数据流概览

```
  Camera Sensor
      │
      ▼
 ┌─────────┐
 │ 采集模块 │  MIPI CSI / DVP RX
 └────┬────┘
      │ 像素流
      ▼
 ┌─────────┐
 │ 帧缓存  │  DDR / BRAM Ping-Pong
 └────┬────┘
      │
      ▼
 ┌─────────┐
 │ 去畸变  │  查表 remap + 双线性插值
 └────┬────┘
      │
      ▼
 ┌─────────┐
 │ 输出模块 │  HDMI / 显示器 / DMA
 └─────────┘
```
