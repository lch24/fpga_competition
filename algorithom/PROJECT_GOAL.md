# 项目目标与当前实现

目标是在 FPGA 上独立完成图像采集、棋盘角点检测、相机参数计算和去畸变显示。当前流程是多张标定图逐张检测，收齐角点后计算参数，校正最后一张原图并静态显示。

资源目标为装入 PG2L100H；算法时钟目标 40 MHz，期望标定耗时几秒、720p 校正图生成在一秒内。是否达成以当前整板实现和对应分辨率的测量为准。

整帧数据放 DDR，片上保存局部缓存和计算工作区。复杂控制与数值迭代使用专用微程序执行器，持续像素处理和采集显示保留专用电路。后续可在稳定的标定参数基础上扩展连续视频校正。

当前代码入口和结构见[根 README](../README.md)、[系统架构](../docs/SYSTEM_ARCHITECTURE.md)，C++ 用于算法参考与数值对照。
