# 三张图的相机标定与去畸变

在 Visual Studio 中重新生成并运行 `Debug | x64`。主程序读取 `test0.jpg`、`test1.jpg`、`test2.jpg`，要求三图尺寸相同且每图检测到完整的 **5 行 × 8 列内角点**。控制台输出参数及误差，三个窗口同时显示左侧原图、右侧校正图。关闭全部窗口退出。

## 纯 C++ 计算链路

完整相机标定统一位于 `algo/calibrate.cpp`，通过 `calibrate.h` 暴露 `calibrate_camera`。

1. 用归一化 DLT 估计各张棋盘的单应矩阵。
2. 使用 Zhang 内参初始化及多个初始焦距候选。
3. 联合优化焦距、主点、每张棋盘的六自由度姿态及畸变系数。
4. 检查收敛、内参范围、重投影误差、姿态变化及采样网格上的映射雅可比；检查失败时不应用校正。
5. 生成一次映射表，复用于三张彩色图，自写双线性插值完成校正。

Jacobi 特征分解、Rodrigues 旋转、数值雅可比、列缩放 LM、高斯消元、映射与插值均由项目代码实现。`algo/` 和 `common/` 不包含 OpenCV 依赖。

假设同一相机、固定分辨率、平面等边方格棋盘、零 skew。物理格长未知时使用 `square_size=1`，只影响平移单位，不影响内参和畸变。内部以棋盘中心为坐标原点改善数值条件，输出姿态以首个内角点为原点。

三张图默认拟合 `k1,k2,p1,p2`，固定 `k3=0`，减少高阶参数过拟合。`CameraCalibrationOptions::estimate_k3=true` 可以启用第五项；此选项已在六幅已知真值的合成数据上验证。

去畸变保留原来的内参和图像尺寸：理想目标像素 → 正向畸变模型 → 源图坐标。源图之外填黑，不复制边缘像素形成拖影。`remap_bilinear` 支持复制边缘和黑色边界，主程序显式选择 `ConstantBlack`。支持灰度、三通道彩色、原位处理和单像素图像。

| 校正图最大单通道像素差异 | 2 / 255 |

RMS 为 `sqrt(sum(dx²+dy²)/角点总数)`。OpenCV 仅作为测试参考，使用同一组自研角点、同一模型设置，不向自研算法提供初值或优化结果。映射坐标和最终像素比较也独立执行。

只有三张图，因此结果会标为 provisional。低重投影误差不证明整个视场的参数精度，纸板不平、镜头变化和棋盘覆盖不足仍可能导致偏差；映射检查是有限网格上的筛查，不是全域数学保证。这里校正镜头畸变，不执行棋盘透视拉正。

## 重跑验证

从仓库根目录运行：

```powershell
& .\closer2fpga\tests\run_calibration_tests.cmd
```

脚本先运行 OpenCV 数值对照测试，再编译并执行一个**不指定 OpenCV 头文件目录、不链接任何 OpenCV 库**的标定/去畸变程序。两部分均已通过。另覆盖格长与平移、网格翻转、视图不足/重复、缺失/非有限角点、无效格长、迭代不足、灰度/彩色恒等映射、原位处理、1×1 图像、黑色边界部分插值、非有限映射坐标和无效输入。

测试生成的校正图位于 `tests/build/calibration_test*_undistorted.png`。编译产物在忽略的 `tests/build` 目录中。

`tests/build_demo.cmd` 用于检查完整桌面程序的编译与链接，不启动窗口。已完成此构建；GUI 显示仍需人工运行检查。脚本默认 `VS_ROOT=E:\vs`，`OPENCV_ROOT=%VS_ROOT%\vcpkg\installed\x64-windows`，可用环境变量覆盖。日常运行建议使用 Visual Studio。
