# 棋盘内角点检测验证

本轮只修改内角点检测、排序、亚像素定位和检查界面。算法模块保持纯 C++；OpenCV 用于图片输入输出、显示及测试参考。未接入相机参数求解或去畸变。

## 手动检查

在 Visual Studio 中运行 `Debug | x64`。默认读取仓库根目录的 `test0.jpg`、`test1.jpg`、`test2.jpg`，内角点尺寸为 **5 行 × 8 列**。

- 绿色细十字标出内角点，蓝色连线显示网格。
- 三个独立窗口同时显示三张标注图；关闭全部窗口后退出，无需按键切换。
- 主程序仅显示三张标注图，不注册鼠标回调，不导出文件。

## 实现和适用边界

- 大图优先在图像金字塔中搜索网格，再回到原图定位；失败时尝试原分辨率。
- 双尺度圆环亮暗交替检查替代固定方向的四象限筛选。
- 搜索棋盘方向后组织行列，检查两个方向的间距变化及网格单元的凸性。
- 使用迭代高斯加权梯度交点定位，不再追加质心偏移。退化或不收敛的点保留初值。
- 不推算缺失的内点。无标记棋盘无法确定唯一物理原点，输出采用图像相对原点。

这仍是启发式检测器：严重透视、强畸变、遮挡、极小棋盘和复杂背景尚未得到全面覆盖。方向搜索仍要求某个投影方向上各行可以分离；参数中也保留了像素级窗口上下限。通过本测试集不等于支持任意图像或任意镜头。
