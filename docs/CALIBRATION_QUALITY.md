# 完整畸变模型与精度评价

## 当前求解流程

初值 → 联合 LM → FP32 发布前检查。生产路径始终拟合 `fx/fy/cx/cy`、
`k1/k2/p1/p2/k3` 和每张图的六个姿态参数。覆盖位只用于诊断，不选择拟合模型。

设计依据是：只最小化角点重投影误差时，k1、k2、k3 可以相互抵消，
在角点附近得到较低误差，却在图像边缘急剧弯折。当前把曲线形状纳入每次
LM 更新的目标，让三项径向系数一起优化，而不是事后删掉高阶项。

## LM 的形状残差

令 `T` 为覆盖输出图像四角的最大归一化半径平方，`q=r²/T`。
径向增益写成 `g(q)=1+Aq+Bq²+Cq³`，其中 `B=k2*T²`、`C=k3*T³`。
用两个残差约束整个视场内的曲率：

```text
e0 = 0.05 * sqrt(N) * (2B+3C)
e1 = 0.05 * sqrt(N) * sqrt(3) * C
e0²+e1² = 0.05² * N * integral_0^1 [g''(q)]² dq
```

`N` 是所有视图的角点总数。这是温和的形状先验，会引入一定估计偏差；
没有把任何人工畸变参数作为目标值，也没有对 k3 单独设置正负或数值范围。
数据能够识别高阶项时，角点误差仍能驱动非零 k3。

另两个残差让更新在接近映射退化之前减速。对 `z=r²`，径向雅可比的两个
特征值为 `1+k1*z+k2*z²+k3*z³` 和 `1+3*k1*z+5*k2*z²+7*k3*z³`。
程序检查 `[0,T]` 的端点及导数全部实根，求两个三次多项式的最小值，
再减去切向项的保守界 `6*sqrt(T*(p1²+p2²))`，得到两个安全裕量 m。
每个 m 对应 `0.01*sqrt(N)*max(0,0.1/m-1)`；接近零时使用有限的线性延伸，
避免差分探针出现除零。

LM 对全部角点残差加这四项残差建立同一个正规方程，仍使用列归一化、阻尼
和主元消元。只有总代价下降且两个裕量均大于 `1e-4` 才接受试探状态；
否则增加阻尼重新求步长，k3 始终保留。这个圆盘判据比只检查图像矩形更保守。
有限差分探针允许跨出可行域，否则无法形成把解拉回合理区域的梯度。

对外报告的 RMS **只由角点误差计算**，不包含这四项先验残差。
最后仍对实际发布的 FP32 参数做 33×25 全图映射检查，检查失败则报告候选
参数和原因，不隐藏失败。无翻折是合理性的证据，不是边缘精度的真值证明。

## 实现组织

`build_lm.py` 组织初始目标、差分雅可比、正规方程、阻尼求步、接受/重试和退出。
`build_lens.py` 生成形状残差与极值计算指令，`lens_policy.py` 提供独立软件公式。
HOST 服务返回原来的 `2N` 项角点残差，程序再追加四项形状残差。
全局相机参数列包含这些残差；各视图姿态列在四项形状残差处为零，按各自视图行区间复用存储。

`build_validate.py` 用发布到校正通路的 FP32 参数检查最终映射。
`calib_top` 负责结果有效性和候选诊断；检查失败不会将候选发布为有效校正参数。
程序、RAM 与 RTL 接口见[标定架构](CALIBRATION_ENGINE_ARCHITECTURE.md)。

## 如何量化准确程度

| 指标 | 回答的问题 | 数据要求 |
|---|---|---|
| 总 RMS、各图 RMS、最大点误差 | 模型能否解释用于拟合的角点 | 检测坐标与拟合状态 |
| 中央/边缘分区残差 | 观测范围内是否存在空间偏差 | 同次角点和处理尺寸 |
| 独立网格的坐标误差 | 参数推导的映射是否准确，包括未放棋盘的区域 | 合成镜头真值或独立参考映射 |
| 校正后直线偏差 | 实际图像是否还有几何弯曲 | 同次原图与校正图 |
| 最小映射雅可比裕量 | 映射是否翻折或接近退化 | 相机参数及输出视场 |

低 RMS 只代表拟合点附近误差小；映射无翻折只代表局部合理，不等于边缘准确。
三项径向系数会相互补偿，比较时应看整条径向曲线和坐标误差，不能单看 k3 的大小。
形状先验会带来一定偏差，其作用是约束观测不足区域的外推。

人工畸变实验中，输入还包含真实镜头自身的畸变、采样插值和检测误差；
拟合参数不必逐项等于人工预设。真值只用于生成输入及独立评分，不传给标定器。
裁剪后使用裁剪尺寸和对应主点，显示放大后的像素误差需换回处理坐标再比较。

## 数据和复算入口

真实角点保存在 `data/calibration`；新采集放在 `data/debug`，有回归价值后再归档。
数据中的历史候选参数是当次观测，不作为新算法的正确答案。

```powershell
python scripts/debug/uart_monitor.py COM5 --corners data/debug/current_corners.json
python scripts/debug/inspect_calibration.py data/debug/current_corners.json
python scripts/debug/replay_calibration.py data/debug/current_corners.json
python scripts/calibration/engine/check_lens_program.py
python scripts/calibration/engine/check_lens_quality.py
python scripts/calibration/engine/check_lm_lens.py
```

`inspect_calibration.py --images raw0.png raw1.png raw2.png` 可叠加编号角点。
`check_lens_program` 检查指令与独立形状公式，`check_lens_quality` 用已知镜头和带噪角点评价边缘误差，
`check_lm_lens` 连接真实共享指令核、RAM 和浮点电路验证完整求解。
比较参数拟合与映射误差时，应使用同次拍摄、同一尺寸、同一任务号的数据。
