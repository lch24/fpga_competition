# 自主浮点算术实现与验证

[fp_operator.v](../rtl/math/fp_operator.v)保持原来的请求/响应接口，支持FP_W=32和64。只有时钟、复位和位向量端口，不依赖外部算术库、real、DPI或仿真数学函数。

## 实现划分

| 文件 | 职责 |
| --- | --- |
| ../rtl/math/fp_operator.v | 请求锁存、特殊值分类、迭代状态机、结果背压保持 |
| ../rtl/math/fp_divsqrt.v | FP32/FP64逐拍除法、平方根，共享请求/响应接口 |
| ../rtl/math/fp_bits.vh | 基础浮点运算、规格化、舍入、非规格化数和精度转换函数 |
| ../rtl/math/fp_constants.vh | Q128常量、128项CORDIC角度表、1280位2/pi |
| generate_fp_constants.js | 以1536位整数精度生成常量；Machin公式、atan/atanh级数及整数开方 |

基础运算使用整数尾数运算，统一按最近偶数舍入。加减保留保护位/舍入位/粘滞位；乘法保留完整尾数积；除法计算整数商和余数；平方根采用逐两位试商的整数开方。支持非规格化数，不默认将其冲零。

超越函数的内部变量为192位有符号定点，其中128位为小数：

- exp：x=k*ln2+r，r约束到半个ln2范围，32轮Taylor累加，再按2^k缩放和浮点舍入。
- log：x=m*2^k，计算z=(m-1)/(m+1)，用40项atanh级数恢复log(m)，加k*ln2。非常接近1时使用浮点短级数，避免固定小数的绝对误差影响小结果。
- sin/cos：用1280位2/pi对整个有限浮点输入范围进行象限和余角计算，再进行128轮CORDIC；极小输入使用解析近似分支。
- atan2：先处理带符号零、无穷大和象限，再对缩放后的向量作128轮CORDIC；极小正x方向的比值使用浮点除法避免定点量化成0。
- acos：域为[-1,1]，使用atan2(sqrt((1-x)*(1+x)),x)，并处理端点。

这些是**近似超越函数**，没有宣称全部输入都保证正确舍入；已测试向量的误差不能当作全输入误差证明。基础运算和转换则按逐位相等与异常标志验证。

## 握手与异常

req_valid&&req_ready时接收；结果有效后一直保持至rsp_ready。每实例一次一笔在途。FP32↔FP64转换命令仅FP_W=64实例支持，FP32结果的高32位清零。

加减、乘法、比较和转换的组合计算结果在接收请求的上升沿后登记；除法、平方根及exp/log/CORDIC需要多个周期。不能仅凭操作名假定延迟，必须观察rsp_valid。结果等待期间不接受新请求；复位取消正在计算或等待接收的结果。

### 除法与平方根的逐拍实现

fp_operator内部独占调用fp_divsqrt，外部接口不变。接收操作数后，依次执行分类、尾数归一化、准备、逐位迭代、舍入打包、保持响应。除法每拍产生一位商；平方根每拍带入两位被开方数并产生一位根。余数非零作为sticky参与最近偶数舍入。迭代之间有寄存器，不再将全部步骤展开在一个周期内。

| 配置 | 除法迭代轮数 | 开方迭代轮数 | 普通除法核心延迟 | 普通开方核心延迟 |
| --- | ---: | ---: | ---: | ---: |
| FP32 | 28 | 27 | 31拍 | 30拍 |
| FP64 | 57 | 56 | 60拍 | 59拍 |

核心延迟从fp_divsqrt接收请求的时钟沿计至响应有效；fp_operator另有请求转发与结果接收开销。非规格化输入按每拍左移一位归一化，最多增加23/52拍；NaN、无穷大、零等特殊情况提前返回。上层仍须使用握手，不应写死等待拍数。

acos内部开方、接近1的log分支中的浮点除法、极小比值atan2中的浮点除法也调用同一核心。exp/log定点级数中的整数除法不属于这个浮点核心，本次保留原实现，等待实际关键路径报告后再评估。

flags由低到高为invalid、divide_by_zero、overflow、underflow、inexact。下溢按舍入后微小且不精确判断。NaN统一返回canonical quiet NaN，不保留payload；输入signaling NaN置invalid。COMPARE遇任意NaN置unordered，仅signaling NaN置invalid；+0与-0比较相等。

超越函数除明确的精确特殊值外保守置inexact。负数开方、log负数、acos越界、sin/cos无穷大返回NaN并置invalid；log(±0)返回负无穷大并置divide_by_zero。atan2参数顺序固定为(y,x)。

## 运行与参考模型

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File E:\fpga\parameter\sim\run_fp_operator.ps1
```

输出位于build_fp/：simulation.log、fp32_results.txt、fp64_results.txt。脚本对超时、非零错误数和缺失通过标记返回失败。测试平台分别实例化FP32和FP64，检查数值、异常标志、比较结果、响应背压保持，以及计算途中/结果等待中的复位。

vectors32.txt、vectors64.txt已提交，可直接运行，不要求本机安装数值库。generate_fp_vectors.js可用Node.js重新生成：基础四则及转换的参考模型使用BigInt有理数和独立舍入逻辑；平方根及超越函数使用JavaScript Math参考。针对宿主atan2极小负数下溢可能丢失负零符号的情况，参考生成器显式恢复数学要求的符号。参考模型不调用被测Verilog函数。

覆盖NaN/Inf/带符号零、最小非规格化数、规格化边界、最大有限数、随机原始位模式、宽指数范围、接近1的log、acos端点、接近pi的三角函数及巨大角度。随机种子固定，可重现。

最近一次ModelSim SE-64 10.1c结果：

| 配置 | 数值向量数 | 错误数 | 基础运算/转换误差 | 超越函数最大实测误差 |
| --- | ---: | ---: | --- | --- |
| FP32 | 9,421 | 0 | 逐位一致 | 1 ULP |
| FP64 | 10,828 | 0 | 逐位一致 | 1 ULP |

总计20,249组向量。超越函数验收阈值设置为8 ULP，当前这组测试的最大实测为1 ULP。ULP是相邻浮点数的间距，不能理解成固定的像素误差；完整标定算法仍需单独对拍。

另外直接测试fp_divsqrt：FP32、FP64各7组场景，均0错误。检查准确的迭代轮数与延迟、非规格化归一化、操作数锁存、忙时拒绝请求、响应背压，以及除法/开方/归一化途中复位后的恢复。结果见build_fp/divsqrt32_results.txt和divsqrt64_results.txt，错误数纳入同一仿真通过条件。

## 当前工程限制

本版是可综合语法的功能基线，**尚未完成目标器件综合、布局布线、资源与时序验证**。浮点除法和平方根已改为逐拍迭代；宽乘法、定点级数中的整数除法、范围缩减及舍入打包仍可能形成较长组合路径。后续依据真实关键路径报告优化；功能仿真通过不能证明达到目标频率。

本机ModelSim退出时已有的FileWatch Tcl报错仍可能出现；当前两种配置完成全部检查，进程退出码为0，且脚本额外确认通过标记。它不替代数值结果检查。
