# jacobi_eigen 实现与验证

实现：[jacobi_eigen.v](../rtl/math/jacobi_eigen.v)。测试：[tb_jacobi_eigen.sv](tb_jacobi_eigen.sv)。参考算法：[C++ symmetric_eigen.cpp](../../algorithom/closer2fpga/closer2fpga/common/symmetric_eigen.cpp)。

支持6×6和9×9实对称FP64矩阵，分别用于Zhang初始化和DLT。输出最小特征向量以及最小、次小、最大特征值。它不构造DLT/Zhang约束矩阵，也不判断棋盘几何是否退化。

## 使用接口

1. cmd_valid&&cmd_ready时锁存cmd_n，只接受6或9。
2. matrix_valid&&matrix_ready时接收一个FP64元素，行优先，共n*n拍；仅最后一个元素matrix_last=1。允许输入空拍。
3. 矩阵完整载入后自动计算，等待rsp_valid。
4. status=OK时，向量第i项在rsp_min_vector_fp64[64*i +:64]，n=6时高3槽为0；三个特征值按数值升序定义。
5. rsp_ready=0时所有响应字段保持；响应接收后才能接受新任务。复位取消计算或待接收的响应。

错误响应的数值结果清零，rsp_rotations保留当前任务已完整执行的旋转数，便于分析失败阶段。新命令和复位清零计数。

| 状态 | 情况 |
| --- | --- |
| BAD_CONFIG | n非法、last位置错误、输入不对称、迭代上限参数非法 |
| CALIB_INVALID | NaN/Inf、算术无效/除零/溢出、达到搜索轮数上限仍未完成 |

非有限输入仍先接收本矩阵剩余数据，再返回失败；提前last则立即结束，不能继续发送旧矩阵。没有输入等待超时，调用方须按契约提供完整数据。

## 计算组织

A和V各保存81个FP64元素，固定9槽行跨度；V在输入矩阵时初始化为单位阵。使用同步双读、单写访问；工作存储不整体复位。资源是否映射成块RAM仍需综合确认。

计算流程：

```text
载入A并初始化V
→ 检查对称性
→ 扫描上三角，找最大非对角绝对值及最大对角绝对值
→ 判断收敛
→ 获取app/aqq/apq并计算旋转角、cos、sin
→ 更新A中p/q两行两列及对角项
→ 更新V的p/q两列
→ 开始下一轮扫描
→ 收敛后排序索引、读取最小特征值对应的V列、发布结果
```

复用一个fp_operator实例。微步骤表依次发送乘、加、减、atan2、sin和cos操作，每步独立等待握手；不会假定超越函数一拍完成。A/V成对读取旧元素后才更新，A对称位置分别写入同一结果。

角度和更新公式沿用C++，包括乘加的求值顺序及分开舍入。停止条件为：

```text
largest <= 1e-14 * max(max_abs_diag, 1e-30)
```

默认最多100*n*n轮搜索，即6阶3600轮、9阶8100轮。最后允许的一轮若仍需旋转，旋转完成后返回未收敛，不额外增加一次检查，保持C++循环边界。参数MAX_SEARCH_ROUNDS默认0，表示采用上述规则；非零可降低或指定搜索上限（1..16383），测试用1强制覆盖非收敛退出。

收敛后仅对特征值索引稳定排序，不搬移整个V矩阵；按排序后的第一个索引读取最小特征向量。重复特征值保留原列顺序。特征向量符号不唯一，重复特征值的特征子空间基也不唯一，不能要求与另一求解器逐位一致。

对称性是精确数值匹配，+0/-0视为相等；不做平均化修正。相较参考源码增加了显式输入有限性、对称性和中间结果检查。

## 仿真运行

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File E:\fpga\parameter\sim\run_jacobi_eigen.ps1
```

ModelSim SE-64 10.1c结果：**30组矩阵＋8组接口/复位场景＋2组搜索上限场景，0错误**。浮点除法/平方根改为逐拍迭代后已重新回归通过，本组最大等待周期为128,090拍；这不是所有输入的固定延迟或板上频率测量。gauss_solver的45组矩阵及8组接口/复位回归也全部通过。

| 测试类别 | 内容 |
| --- | --- |
| 两种维度 | 6×6、9×9，交替任务后未使用向量槽保持0 |
| 谱的形态 | 零矩阵、单位阵、乱序对角、全负对角、正定、非正定、秩亏、重复/接近特征值 |
| 旋转与尺度 | 已知2×2嵌入块；随机正交变换构造稠密矩阵；1e-20、1e100、1e-40尺度 |
| 异常输入 | NaN、Inf、不对称矩阵、角度计算溢出 |
| 数据协议 | 连续输入、输入空拍、命令锁存、非法n、提前/缺失last、响应背压及拒绝新任务 |
| 复位 | 输入途中、旋转算术途中、响应未接收时复位，随后重新计算 |
| 搜索上限 | 上限为1时对角矩阵成功；需要旋转的矩阵完成1次旋转后返回未收敛 |

参考数据来自独立构造A=Q*D*Q^T，已知特征值D和正交矩阵Q，没有复制RTL的Jacobi迭代。测试执行：

- 检查最小、次小、最大特征值及排序；单特征值误差除以scale后小于2e-11。
- 检查向量有限、未用高槽为0，以及|v^T v-1|<1e-10。
- 对最小特征值隔离良好的用例，允许符号翻转后与已知向量对照。
- 使用原始输入A，独立计算max_i|A*v-lambda*v|/scale，要求小于2e-11。

其中scale=max(||A||_inf,1e-30)。当前测试最大归一化残差为 **3.929842e-15**，最大|v^T v-1|为 **1.110223e-15**。这些是此组测试的实测值，不是全部输入的误差上界。极小矩阵受算法中的1e-30尺度下限影响，不能据此宣称相对原矩阵仍保持同等精度。

eigen_vectors.txt可直接用于仿真，eigen_cases.txt记录用例名称；generate_eigen_vectors.js可使用Node.js重新生成数据。结果位于build_eigen/eigen_results.txt与simulation.log。脚本同时检查完成标志、用例数量、错误数和进程退出码。
