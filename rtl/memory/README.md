# 存储与访存组织

`ddr` 负责逻辑请求仲裁、物理 HMIC 适配和返回归属；`image` 负责灰度/候选的 DDR 访问、搬运与局部缓存；`parameters` 保存角点及相机参数；`local` 提供同步 RAM 和标定工作存储。

完整原图、校正图、灰度金字塔和映射表都在 DDR。角点按 view/点号进入片上 RAM，标定阶段只读角点，不读图像。计算工作 RAM 在初值、LM、检查之间复用。

DDR 接口以字节为地址单位，标定工作区以 64 位字为单位。同步 RAM 读地址采样后返回数据，控制器明确安排等待拍；FIFO 和响应槽解耦独立客户端。地址分区见根 README。

整体流程见[系统架构](../../docs/SYSTEM_ARCHITECTURE.md)，其他模块入口见[RTL 导航](../README.md)。
