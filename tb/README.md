# 仿真测试平台

全部 HDL 测试平台集中在这里；运行入口见 [scripts](../scripts/README.md)，输入与参考数据见 [data](../data/README.md)。TB 和厂商端口桩不能加入 PDS 综合源码清单。

| 子目录      | 检查对象                                                                              |
| ----------- | ------------------------------------------------------------------------------------- |
| calibration | 初始化、雅可比、正规方程、LM、结果校验、标定任务控制                                  |
| compute     | 浮点、矩阵、投影/旋转、共享计算服务；`stream` 与 `remap` 保留两种不同的 FP32 测试 |
| memory      | 角点缓存、DDR 适配/仲裁、DMA、灰度与候选缓存                                          |
| image       | 灰度、响应、筛选、排序、亚像素、棋盘检测                                              |
| remap       | 坐标映射、建表、校正及参数存储                                                        |
| video       | 摄像头/显示接口、跨时钟、板级配置时钟                                                 |
| system      | DDR 闭环、摄像头闭环、板级调度、端到端数值检查                                        |
| models      | DDR 行为模型及公共测试连接头文件                                                      |

维护约定：TB 只描述激励与检查；工具调用和退出状态检查放在 `scripts`；期望数据由独立参考模型生成到 `data`。新增用例优先覆盖修改范围，完整 LM 按需运行。两个 `tb_fp32` 对应不同被测模块，使用各自独立编译库，不能同时编入同一个库。
