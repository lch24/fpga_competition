# 实拍角点：FPGA与C++对比结果

2026-09-30，使用 `data\real\run_1790731382958_0` 的120个实拍角点完成ModelSim SE-64 10.1c顶层仿真。

**结果：PASS。50项数值全部通过，TB错误数0。9个FP32相机参数中8个逐位相同；k2相差1 ULP，绝对差3.725290298461914e-9。**
