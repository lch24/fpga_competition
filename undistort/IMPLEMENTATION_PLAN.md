# 去畸变模块实施规划

本文以 `main` 分支根目录 `README.md` 为接口与分工的唯一依据，代码在
`undistort` 分支开发。我们的输入边界是已经通过有效性检查的一笔相机参数包，
输出边界是写回 DDR 的校正图像及完成响应。

## 1. 固定边界

- 输入参数采用 IEEE 754 FP32 位模式，顺序固定为
  `fx,fy,cx,cy,k1,k2,k3,p1,p2`。
- 参数包同时携带 `calib_id[31:0]`、`width[15:0]`、`height[15:0]` 和
  `camera_valid`。首版只消费成功完成响应对应的有效参数包。
- 映射表是两个 FP32 平面：`map_x` 与 `map_y`，地址单位统一为字节。
- 图像首版采用 BGR888；映射方向为输出像素反查源图坐标。
- 算法模块只连接抽象 DDR 服务，不直接连接 HMIC/AXI/DDR PHY。

## 2. 模块边界

```text
有效九参数
    |
    v
map_build_ctrl --光栅坐标--> map_coord_core --sx/sy--> map_table_writer --> DDR map_x/map_y
                                                                  |
                                                                  v
DDR源图 --> map_reader --> sample_coord --> neighbor_fetch --> bilinear --> output_writer --> DDR输出图
```

### 建表子系统

1. `map_build_ctrl`：锁存一次任务参数；配置坐标核和映射写入器；按照
   `(0,0)` 到 `(W-1,H-1)` 发出坐标；等待最后一项计算结果及 DDR 写完成后响应。
2. `map_coord_core`：FP32 实现 Brown 模型，输入一个目标整数坐标，输出一个
   FP32 源坐标。首版可串行复用 FP 运算服务，正确后再流水化。
3. `map_table_writer`：把顺序 `sx/sy` 分别写入两个 FP32 平面；行尾遵守
   `map_stride_bytes`；只有两个平面全部写完成才返回成功。

### 帧校正子系统

1. `map_reader`：顺序读取并按 `pixel_id` 配对 map_x/map_y。
2. `sample_coord`：检查有限值，执行 floor，产生 dx/dy 与四邻域有效掩码。
3. `neighbor_fetch`：首版一次只处理一个输出像素，依次收齐最多四个 BGR 像素。
4. `bilinear_core`：三个通道共享同一组权重，保持 C++ 公式顺序。
5. `output_writer`：光栅写回目标图，等待真实 DDR 写完成后才报告完成。

## 3. 实施里程碑

| 里程碑 | 交付与验收 |
| --- | --- |
| M0 接口冻结 | 公共定义、FP32参数包、DDR抽象事务和错误码与 main README 一致 |
| M1 建表控制 | `map_build_ctrl` 在随机背压下不丢不重，恰好输出 `W*H` 项，写完成前不 done |
| M2 坐标计算 | FP32 Brown 核与 C++ 导出坐标对拍，覆盖零畸变、中心、四角和非法参数 |
| M3 映射写读 | 两个 FP32 平面地址/stride正确，表与 calib_id/W/H 原子绑定 |
| M4 校正闭环 | 注入参考 map，完成边界、四邻域、BGR插值和 DDR 输出 |
| M5 DDR适配 | 抽象32位字节事务适配现有256位DDR IP，验证跨拍、尾字节和写完成屏障 |
| M6 视频集成 | 摄像头帧缓冲、校正任务和 HDMI 显示按帧所有权安全切换 |
| M7 性能优化 | 根据板上计数器加入缓存、多在途或流水；每次优化保持回归 |

当前提交从 M0/M1 开始。M2 在厂商 FP32 IP 的延迟、启动间隔和异常行为冻结后
接入；在此之前不使用 `real` 或 `/` 冒充可综合浮点运算器。

## 4. 验证顺序

1. 小尺寸 4x3 光栅，随机拉低各级 ready，检查坐标、pixel_id、last。
2. 使用恒等参数生成映射，与 `(sx,sy)=(x,y)` 对拍。
3. 使用 C++ 当前九参数导出的全帧 map 对拍。
4. 注入恒等 map，DDR 输入输出逐字节一致且 padding 不变。
5. 覆盖 `sx=-0.5`、右/下边界和整点越界，确认部分邻域仍参与插值。
6. 最后接现有 DDR 控制器与 1280x720 视频，测量周期、实际传输字节和缓存命中率。

## 5. 暂不混入首版的内容

- 标定角点检测、LM 和参数求解属于另外两位成员。
- 定点化不是当前跨模块协议；FP32 正确闭环后再以独立数值模型评估。
- 透视/任意角度拉正不由当前九参数 Brown 去畸变自动完成，若赛题后续需要，另加
  逆单应矩阵阶段，不能修改这九参数的含义。
